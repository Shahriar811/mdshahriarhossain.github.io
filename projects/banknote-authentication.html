Bangladeshi Banknote Authentication System

A computer-vision project that classifies Bangladeshi banknote images as authentic or counterfeit. MobileNetV2 transfer learning powers a binary classifier, with a Flask image-upload interface and saved evaluation reports.

Dataset & recorded counts

The preparation notebook records a source pool of 6,794 banknote images: 2,933 fake and 3,861 real. The evaluation notebook uses a separate 1,668-image test set: 706 fake and 962 real. Inputs are resized to 224 × 224 RGB.

Model architecture

An ImageNet-pretrained MobileNetV2 backbone is frozen for transfer learning. The classifier uses global average pooling, batch normalization, dropout, 128- and 64-unit dense layers, and a final sigmoid output. The notebook records 175,105 trainable parameters.

Training augmentation includes rotations, translations, shear, zoom, and horizontal flips. TensorFlow/Keras performs inference, and a Flask interface accepts image uploads.

Recorded test performance

The evaluation notebook reports 97.48% accuracy and 0.9923 ROC AUC on 1,668 test images. Weighted precision, recall, and F1 are each 97.48% in the saved classification report.
